# Cómo usar AeroCam

## Qué hace AeroCam

AeroCam te permite controlar una cámara DJI Osmo Action vinculada desde tu Karoo durante una ruta.

Puedes hacer fotos, grabar vídeo, añadir destacados y mantener la cámara preparada entre grabaciones. AeroCam también envía datos GPS en directo desde el Karoo a la cámara para la telemetría de vídeo compatible.

## Empezar una ruta

Después de vincular la cámara, el uso normal es sencillo:

1. Inicia la ruta en el Karoo.
2. Enciende la cámara.
3. AeroCam busca automáticamente la cámara vinculada y vuelve a conectarla.
4. Usa los campos de datos de AeroCam cuando se activen.

Si la cámara no vuelve a conectarse, pulsa **Conectar** en el campo Control de cámara.

> **Importante:** La reconexión automática funciona con una cámara encendida. No puede encender una cámara totalmente apagada.

## Elegir un campo de datos

### Control de cámara

Control de cámara funciona mejor como **campo de datos a pantalla completa**. Reúne las principales acciones, el estado de conexión, la batería y el espacio de la tarjeta.

Úsalo cuando el control de la cámara sea importante en tu página de ruta.

### Vídeo

Vídeo está diseñado para un **campo de datos pequeño**. Úsalo principalmente para iniciar o detener grabaciones y añadir destacados.

Funciona bien en una página de mapa o junto a los controles multimedia.

### Foto

Foto también está diseñado para un **campo de datos pequeño**. Ofrece un control grande y sencillo sin ocupar toda la página.

La cámara no puede hacer fotos mientras graba vídeo, por lo que Foto se desactiva durante una grabación.

## Telemetría GPS

Mientras la cámara está conectada, AeroCam envía datos GPS en directo desde el Karoo. La cámara puede guardar los datos compatibles con el vídeo para usarlos en superposiciones de telemetría DJI y editores compatibles.

Las superposiciones disponibles dependen de la cámara, su firmware y el programa de edición.
