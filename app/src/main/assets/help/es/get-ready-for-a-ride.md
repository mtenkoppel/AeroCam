# Consejos para preparar una salida

1. Mantén encendido el Karoo y enciende tu cámara DJI.
2. AeroCam se conectará automáticamente a tu cámara DJI. El campo de datos indica que la conexión se ha establecido correctamente.
3. Ahora bloquea la pantalla de la cámara DJI. Con los ajustes adecuados, la pantalla se apaga y la cámara sigue disponible mientras **Evitar el apagado automático** esté activado.
