# Empfohlene Einstellungen zum Verhindern von Standby

1. Stelle **Auto Power Off** auf **5 Minuten**.
2. Schalte die Kameratöne aus (optional): **Settings → Sounds → Mute**.
3. Stelle **Single Screen Preview** auf **Screen off when locked** (im Menü kann diese Option auch **On** heißen).
4. Verbinde die Kamera und sperre dann ihren Bildschirm. Aktiviere in AeroCam **Kamera wach halten** unter **Einstellungen → Standby verhindern**.

Die Menünamen können je nach Firmware-Version der Kamera etwas abweichen.
