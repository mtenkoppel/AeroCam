# Tipps zur Vorbereitung auf eine Fahrt

1. Lass deinen Karoo eingeschaltet und schalte deine DJI-Kamera ein.
2. AeroCam verbindet sich automatisch mit deiner DJI-Kamera. Das Datenfeld zeigt die erfolgreiche Verbindung an.
3. Sperre jetzt den Bildschirm der DJI-Kamera. Mit den richtigen Einstellungen schaltet sich das Display aus. Die Kamera bleibt verfügbar, solange **Standby verhindern** eingeschaltet ist.
