# Definições recomendadas para evitar o desligamento automático

1. Define **Auto Power Off** como **5 minutos**.
2. Desativa os sons da câmara (opcional): **Settings → Sounds → Mute**.
3. Define **Single Screen Preview** como **Screen off when locked** (o menu pode apresentar esta opção como **On**).
4. Liga a câmara ao Karoo e depois bloqueia o ecrã da câmara. No AeroCam, ativa **Manter a câmara ativa** em **Definições → Evitar o desligamento automático**.

Os nomes dos menus podem variar ligeiramente consoante a versão do firmware da câmara.
