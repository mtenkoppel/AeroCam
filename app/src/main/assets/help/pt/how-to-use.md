# Como usar o AeroCam

## O que faz o AeroCam

O AeroCam permite controlar uma câmara DJI Osmo Action emparelhada a partir do Karoo durante uma volta.

Pode tirar fotografias, gravar vídeo, adicionar destaques e manter a câmara pronta entre gravações. O AeroCam também envia dados GPS do Karoo para a câmara para telemetria de vídeo compatível.

## Iniciar uma volta

Depois do primeiro emparelhamento:

1. Inicie a volta no Karoo.
2. Ligue a câmara.
3. O AeroCam procura automaticamente a câmara emparelhada e volta a ligar.
4. Use os campos de dados AeroCam quando ficarem ativos.

Se a câmara não voltar a ligar, prima **Ligar** no campo Controlo da câmara.

> **Importante:** A reconexão automática funciona com uma câmara ligada. Não consegue ligar uma câmara completamente desligada.

## Escolher um campo de dados

### Controlo da câmara

Controlo da câmara funciona melhor como **campo de dados de ecrã completo**. Reúne as principais ações, a ligação, a bateria e o espaço do cartão.

Use-o quando o controlo da câmara for importante na página da volta.

### Vídeo

Vídeo foi pensado para um **campo de dados pequeno**. Use-o sobretudo para iniciar ou parar gravações e adicionar destaques.

Funciona bem numa página de mapa ou junto aos controlos multimédia.

### Fotografia

Fotografia também foi pensado para um **campo de dados pequeno**. Oferece um controlo grande e simples sem ocupar toda a página.

A câmara não consegue tirar fotografias enquanto grava vídeo, por isso o campo fica desativado durante uma gravação.

## Telemetria GPS

Quando a câmara está ligada, o AeroCam envia dados GPS do Karoo em tempo real. A câmara pode guardar os dados compatíveis com o vídeo para sobreposições DJI e programas de edição compatíveis.

As sobreposições disponíveis dependem da câmara, do firmware e do software usado.
