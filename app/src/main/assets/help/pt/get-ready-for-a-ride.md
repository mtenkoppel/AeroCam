# Dicas para preparar uma volta

1. Mantém o Karoo ligado e liga a tua câmara DJI.
2. O AeroCam liga-se automaticamente à tua câmara DJI. O campo de dados indica que a ligação foi estabelecida.
3. Agora bloqueia o ecrã da câmara DJI. Com as definições corretas, o ecrã desliga-se e a câmara continua disponível enquanto **Evitar o desligamento automático** estiver ativado.
