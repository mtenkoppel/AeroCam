# Télémétrie GPS

Lorsque la caméra est connectée, AeroCam transmet en direct les données de télémétrie GPS du Karoo. La caméra peut enregistrer les données compatibles avec la vidéo pour les utiliser dans les incrustations de télémétrie DJI et les logiciels de montage compatibles.

Les incrustations disponibles dépendent de la caméra, de son micrologiciel et du logiciel utilisé pour monter la vidéo.
