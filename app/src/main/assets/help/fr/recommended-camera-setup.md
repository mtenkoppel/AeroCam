# Réglages recommandés pour empêcher l’arrêt automatique

1. Règle **Auto Power Off** sur **5 minutes**.
2. Désactive les sons de la caméra (facultatif) : **Settings → Sounds → Mute**.
3. Règle **Single Screen Preview** sur **Screen off when locked** (le menu peut afficher cette option comme **On**).
4. Connecte la caméra, puis verrouille son écran. Dans AeroCam, active **Garder la caméra active** sous **Réglages → Empêcher l’arrêt automatique**.

Les noms des menus peuvent varier légèrement selon la version du micrologiciel de la caméra.
